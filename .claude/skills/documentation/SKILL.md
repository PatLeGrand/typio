# Documentation

Mettre à jour la doc seulement si le changement modifie ce qu'un utilisateur ou développeur doit savoir : installation, commandes, configuration, variables d'environnement, API publique, comportement visible.

- Modifier la section existante concernée plutôt qu'ajouter une nouvelle page.
- Ne pas créer de fichier de documentation non demandé.
- Exemples courts et exécutables plutôt que des explications longues.
- Supprimer ce que le changement rend faux.
- Suivre le ton et le format du document existant.
